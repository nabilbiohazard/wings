Wings Commerce 1.1.1 — OTP کنسول ملی‌پیامک

نصب: فایل ZIP را در افزونه‌ها > افزودن > بارگذاری نصب و جایگزینی نسخه قبلی را تأیید کنید.
تنظیمات: ووکامرس > اتصال وینگز
روش ارسال پیامک: OTP کنسول ملی‌پیامک
کلید اختصاصی OTP: فقط رشته ۳۲ کاراکتری بعد از /api/send/otp/ در آدرس پنل؛ کل آدرس را وارد نکنید.
کلید اتصال سایت باید همان مقدار WINGS_BRIDGE_SECRET در Next.js باقی بماند.
در روش کنسول نام کاربری، رمز وب‌سرویس و bodyId لازم نیست.

تنظیم جایگزین در wp-config.php (قبل از خط پایان و بدون کلید واقعی در گیت):
define('WINGS_SMS_PROVIDER', 'console');
define('WINGS_MELIPAYAMAK_OTP_KEY', 'YOUR_32_CHARACTER_OTP_KEY');
ثابت‌های wp-config.php بر تنظیمات پیشخوان اولویت دارند.

کد سرویس در سرور هش می‌شود؛ پاسخ auth/request فقط challenge و retry_after است.
کد ۵ دقیقه اعتبار دارد و حداکثر ۵ تلاش برای هر چالش پذیرفته می‌شود.
کدهای عددی ۴ تا ۱۰ رقمی پذیرفته می‌شوند. نمونه مستندات کنسول ۱۰ رقمی است.
اگر صفحه Next.js یا API واسط آن فقط ۶ رقم می‌پذیرد، محدودیت input، maxLength، الگوی اعتبارسنجی و اعتبارسنجی سرور باید هماهنگ شوند.
این بسته فقط افزونه وردپرس است؛ کد Next.js در فایل ارسالی وجود نداشت و تغییر نکرده است.

HTTPS با اعتبارسنجی گواهی فعال است. هیچ درخواست واقعی پیامک برای بررسی این نسخه ارسال نشده است.
اعتبارسنجی پاسخ بر اساس مستندات ارسالی: HTTP 200، code عددی و status برابر «عملیات موفق»، خالی، null، false یا غایب.
پاسخ نامعتبر یا status حاوی شرح خطا باعث شکست ارسال می‌شود؛ جزئیات پاسخ و کلید به مرورگر نمایش داده نمی‌شوند.

برای تست واقعی پس از نصب، یک بار با شماره خود درخواست کد بدهید و ورود و خروج را بررسی کنید.
در محیط ساخت PHP نصب نبود؛ lint و تست اجرایی PHP/وردپرس انجام نشد. رفتار واقعی باید روی هاست بررسی شود.
