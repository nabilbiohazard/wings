# گردنبند حلقه‌دار

نام دسته‌بندی ووکامرس: «گردنبند حلقه‌دار»
نامک پیشنهادی: ring-necklace

این دسته را به محصول جدید بدهید و تصویر ring-necklace.webp را بدون برش یا تغییر حاشیه به عنوان تصویر اصلی محصول بارگذاری کنید. مختصات ۱۹ حلقه اصلی از همین تصویر مربع استخراج شده‌اند؛ قفل و زنجیر تنظیم طول محل اتصال چارم نیستند. هر حلقه یک چارم می‌پذیرد.

برای فعال شدن اعتبارسنجی سفارش، نسخه تغییرکرده wordpress/wings-commerce/designs.php و فایل necklace-holes.json باید همراه افزونه روی سرور قرار بگیرند.
